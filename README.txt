SPILLWAY WORKBENCH - BUNDLE FOR COLLEAGUE
=========================================

This folder contains everything needed to build
SpillwayWorkbench.exe on a Windows PC.

Quick start:
  1. Make sure Python 3.11+ is installed (python.org/downloads)
     - Check "Add Python to PATH" during install!
  2. Open QUICKSTART_FOR_COLLEAGUE.txt for 4-step instructions
  3. Double-click build_windows.bat

Total time: 10 minutes, fully automatic.

The .exe that gets built will be ~110 MB, fully standalone,
runs on any Windows 10/11 PC without needing Python or any
other software installed.

Questions? See QUICKSTART_FOR_COLLEAGUE.txt for troubleshooting.
